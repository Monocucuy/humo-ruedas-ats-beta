# Humo de ruedas para ATS — BETA

> **BETA para American Truck Simulator (ATS 1.61).** Version **0.4**. Solo para pruebas, uso local.

Mod que hace que los camiones echen humo de llantas, como el Ford Mustang '67 de Road Trip.

## Version 0.4

- `Humo de ruedas W900 v0.4.scs`
- Kenworth W900 con `suspension_class: standard` (17 chasis): echa humo al patinar o frenar fuerte.
- Sonido de llanta del Mustang '67 en las llantas base de camion.

## Instalacion

Copiar el `.scs` a `Documents\American Truck Simulator\mod` y activarlo en el gestor de mods.

## Limitaciones (beta)

- Los remolques no echan humo (el juego solo lo permite en el vehiculo propio).
- Puede cambiar la suspension del W900 (sin evaluar).
- Contiene copias modificadas de archivos del juego (SCS Software). No es oficial. Tras cada actualizacion de ATS hay que regenerarlo.
